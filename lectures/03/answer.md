# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：第1回のLLMはモデルの知識をもとに回答するのに対し、第3回のエージェントは用語集を検索するツールを使い、その結果に基づいて回答した。LoRAについて質問すると、定義とともに関連する第2回が示された。
- `--trace` で見えたツール呼び出し（ツール名と引数）：`search_glossary({"query": "LoRA"})` が呼び出された。また、確認問題を求めると `make_quiz({"lecture": 2})` が呼び出された。
- 1つの質問でのLLM呼び出し回数（`requests`）：2回。LoRAの質問、確認問題の質問ともに2回だった。
- 追加したツールと、docstringに書いた説明：`make_quiz(lecture: int) -> str` を追加した。指定した回の用語集からランダムに1つ選び、確認問題と答えを返す。docstringには「第2回の確認問題を出して」のように復習用の問題を求められたときに使う、と記載した。動作確認では「過学習」の問題が出題され、11個のテストがすべて成功した。

## 宿題

- 取り組んだレベル：基礎
- やったこと：`app/agent.py` の `INSTRUCTIONS` から「用語や講座に固有のことを答える前に、必ず search_glossary で用語集を確認する」という指示を削除し、変更前後で「LoRAとは何ですか？」という同じ質問を `--trace` 付きで実行して比較した。
- 結果：変更前後とも `search_glossary` が `{"query": "LoRA"}` で呼び出され、LLM呼び出し回数は2回だった。回答も用語集に基づいた内容で、大きな違いはなかった。
- 気づき・疑問：必ず検索するという指示を削除しても、今回は検索が実行された。ツールの説明文にも検索する場面が書かれているため、その影響があると考えた。エージェントの動作は `INSTRUCTIONS` だけでなく、ツールの説明文にも左右される可能性があると感じた。
